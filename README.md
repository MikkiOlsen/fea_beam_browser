# fea_beam_browser
A simple browser-based FEA beam calculator built with Rust and WebAssembly.

## Live Demo
You can view the project live here: [https://github.com/MikkiOlsen/fea_beam_browser/](https://MikkiOlsen.github.io/fea_beam_browser/)

## Overview
This tool performs a basic finite element analysis of a beam and renders the **deformed shape** directly in your browser. It doesn't display the stress/moment distribution or anything.
